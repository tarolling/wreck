# x86-64 — SysV ABI (Linux / macOS)

Windows x64 uses a *different* calling convention (rcx,rdx,r8,r9 for args, different callee-saved set, shadow space requirement) — if the target is Windows, ask/confirm before assuming SysV below.

## Syntax
Default to **AT&T syntax** (GNU `as`): `mov %rsi, %rax` reads as src → dst. If the user wants Intel syntax (`mov rax, rsi`, dst ← src), that's fine — just declare which one at the top of the file with `.intel_syntax noprefix` and don't mix mental models mid-file.

## General-purpose registers
| 64-bit | 32-bit | Argument role | Save convention |
|---|---|---|---|
| rax | eax | return value | caller-saved |
| rdi | edi | arg 1 | caller-saved |
| rsi | esi | arg 2 | caller-saved |
| rdx | edx | arg 3 | caller-saved |
| rcx | ecx | arg 4 | caller-saved |
| r8  | r8d | arg 5 | caller-saved |
| r9  | r9d | arg 6 | caller-saved |
| r10 | r10d | — (scratch) | caller-saved |
| r11 | r11d | — (scratch) | caller-saved |
| rbx | ebx | — | **callee-saved** |
| r12-r15 | r12d-r15d | — | **callee-saved** |
| rbp | ebp | frame pointer | **callee-saved** |
| rsp | esp | stack pointer | (special) |

Floating point / vector args: xmm0-xmm7, return in xmm0.

## Calling convention rules
- Integer/pointer args 1-6 in order: `rdi, rsi, rdx, rcx, r8, r9`. Args 7+ go on the stack (pushed right-to-left).
- Return value in `rax` (128-bit values use `rdx:rax`).
- **Stack alignment: `rsp` must be a multiple of 16 immediately before a `call` instruction executes.** Since `call` pushes an 8-byte return address, `rsp % 16 == 8` at the very first instruction of the callee. This is the #1 source of subtle segfaults — when computing local stack space, always verify the arithmetic keeps this invariant, e.g. `sub $24, %rsp` after a standard `push %rbp` (8 bytes) keeps you aligned; `sub $16, %rsp` after that same push would not.
- Caller-saved (assume any `call` clobbers these): rax, rcx, rdx, rsi, rdi, r8-r11. Save them yourself first if you need the value after the call.
- Callee-saved (a function you write must preserve these if it uses them): rbx, rbp, r12-r15.

## Standard prologue / epilogue
```asm
push %rbp
mov  %rsp, %rbp
sub  $16, %rsp        # N must keep rsp 16-byte aligned; N is usually a multiple of 16
# ... body ...
mov  %rbp, %rsp
pop  %rbp
ret
```

## Syscalls (Linux, direct — not libc wrapper)
Syscall number in `rax`; args in `rdi, rsi, rdx, r10, r8, r9` — **note r10, not rcx**, because `syscall` clobbers rcx (return address) and r11 (flags). Trigger with `syscall`. Return value in `rax`; negative value = `-errno`.

## Assemble, link, inspect
```bash
as file.s -o file.o
ld file.o -o file                 # bare syscalls only, no libc
# or, if calling libc functions (printf, malloc, etc.):
gcc file.s -o file -no-pie
objdump -d file                   # verify what actually got encoded
```

## Compiler cross-check (for non-trivial logic)
```bash
gcc -S -O0 -fno-asynchronous-unwind-tables -fno-dwarf2-cfi-asm equiv.c -o -
```
`-O0` keeps the output close to a naive hand-translation, useful for sanity-checking stack layout and register choices. Don't copy it verbatim — use it to catch mistakes.
